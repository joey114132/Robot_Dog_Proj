# 🐶 DogBot AI – Emotion-Driven Robot Dog (Local LLM)

DogBot AI is an experimental robot dog system that translates **sensor-based interactions** into **emotionally expressive text responses** using a **local Large Language Model (LLM)**.

The project focuses on delivering believable emotional feedback **without audio output**, relying solely on **text actions and dog-like expressions** optimized for a **16x2 LCD display**.

---

## 🔍 Project Motivation

Most AI pet projects depend heavily on:
- Speech output
- Cloud-based APIs
- High-performance hardware

DogBot AI explores a different question:

> **Can emotional bonding be conveyed through extremely limited hardware and text-only interaction?**

This project investigates how **prompt engineering**, **context modeling**, and **state translation** can simulate emotional presence under strict constraints.
